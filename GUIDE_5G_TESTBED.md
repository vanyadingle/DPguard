# ПОЛНАЯ ПОШАГОВАЯ ИНСТРУКЦИЯ: РАЗВЕРТЫВАНИЕ 5G-СТЕНДА И ТЕСТИРОВАНИЕ DP-GUARD В РЕАЛЬНОМ ВРЕМЕНИ

Данная инструкция описывает процесс развертывания полноценного исследовательского 5G Standalone (SA) стенда на базе **Open5GS (5G Core)** и **UERANSIM (gNodeB + UE радиосимулятор)**, подключение оркестратора **DP-Guard** и фиксацию ключевых экранов (скриншотов) для курсовой работы или диплома.

---

## 1. СИСТЕМНЫЕ ТРЕБОВАНИЯ И ПОДГОТОВКА СРЕДЫ

Стенд разворачивается на **Ubuntu 22.04 LTS**. Вы можете использовать:
- **Вариант А (Рекомендуется для Windows):** WSL2 (Windows Subsystem for Linux) с Ubuntu 22.04.
- **Вариант Б:** Виртуальная машина VirtualBox или VMware с Ubuntu 22.04 (выделите 4 ГБ ОЗУ и 2-4 ядра CPU).
- **Вариант В:** Физический ноутбук или лабораторный ПК с Ubuntu 22.04.

---

## 2. ШАГ 1. УСТАНОВКА И ЗАПУСК ЯДРА СЕТИ OPEN5GS

Откройте терминал Ubuntu и выполните команды:

```bash
# 1. Обновление пакетов и установка зависимостей
sudo apt update && sudo apt upgrade -y
sudo apt install software-properties-common curl gnupg git -y

# 2. Добавление официального PPA репозитория Open5GS
sudo add-apt-repository ppa:open5gs/latest -y
sudo apt update

# 3. Установка СУБД MongoDB (база данных абонентов) и всех сервисов 5G SA Core
sudo apt install mongodb open5gs -y

# 4. Проверка статуса служб ядра (AMF, SMF, UPF)
sudo systemctl status open5gs-amfd
sudo systemctl status open5gs-upfd
```

> **Что происходит:** Ядро Open5GS поднимает виртуальный сетевой интерфейс `ogstun` (обычно с подсетью `10.45.0.0/16` для IPv4), через который абоненты 5G получают доступ к сети передачи данных.

## 3. ШАГ 2. НАСТРОЙКА WEB-ИНТЕРФЕЙСА OPEN5GS И РЕГИСТРАЦИЯ АБОНЕНТОВ

Open5GS включает графический веб-интерфейс для управления профилями абонентов.

```bash
# 1. Установка Node.js для запуска WebUI
curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -
sudo apt install nodejs -y

# 2. Установка и запуск open5gs-webui
cd /usr/lib/node_modules/open5gs
sudo npm install
sudo systemctl enable --now open5gs-webui
```

### Куда тыкать в браузере:
1. Откройте браузер на хосте: перейдите по адресу **`http://localhost:3000`**.
2. **Логин:** `admin`, **Пароль:** `1423`.
3. Нажмите кнопку **"Subscribers"** в верхнем меню, затем синюю кнопку **"+" (Add Subscriber)**.
4. Введите параметры тестового абонента (по умолчанию совпадают с конфигами UERANSIM):
   - **IMSI:** `999700000000001`
   - **K:** `465B5CE8B199B49FAA5F0A2EE238A6BC`
   - **OPc:** `E8ED289DEBA952E4283B54E88E6183CA`
   - **SST (Slice/Service Type):** `1` (соответствует eMBB)
   - **SD (Slice Differentiator):** `000001`
5. Нажмите кнопку **"Save"**. Зарегистрируйте аналогично второго абонента с IMSI `999700000000002`.

## 4. ШАГ 3. СБОРКА И ЗАПУСК СИМУЛЯТОРА РАДИОДОСТУПА UERANSIM

UERANSIM программно эмулирует базовую станцию 5G (gNodeB) и пользовательские терминалы (UE).

```bash
# 1. Установка инструментов сборки
sudo apt install make gcc g++ libsctp-dev lksctp-tools iproute2 cmake -y

# 2. Клонирование и компиляция
git clone https://github.com/aligungr/UERANSIM
cd UERANSIM
make -j$(nproc)
```

После компиляции в папке `build/` появятся бинарные файлы `nr-gnb` (базовая станция) и `nr-ue` (абоненты).

---

## 5. ШАГ 4. ПОШАГОВЫЙ ЗАПУСК СТЕНДА (ОТКРЫВАЕМ 4 ТЕРМИНАЛА)

Для наглядной демонстрации откройте **4 отдельных окна терминала**:

### Терминал 1: Запуск виртуальной базовой станции (gNodeB)
```bash
cd ~/UERANSIM
./build/nr-gnb -c config/open5gs-gnb.yaml
```
*В консоли появится: `[gNB] [info] Connection established for AMF` (связь по интерфейсу N2 установлена).*

### Терминал 2: Подключение абонентских устройств (UE)
```bash
cd ~/UERANSIM
sudo ./build/nr-ue -c config/open5gs-ue.yaml -n 2
```
*На хосте поднимутся виртуальные сетевые интерфейсы абонентов `uesimtun0` (IP: `10.45.0.2`) и `uesimtun1` (IP: `10.45.0.3`). Сессии PDU активированы.*

### Терминал 3: Генерация трафика и имитация DoS-атаки
1. **Штатный трафик (первое устройство):**
```bash
ping -I uesimtun0 8.8.8.8
```
2. **Атака / Аномальная нагрузка (второе устройство `uesimtun1`):**
```bash
# Генерация всплеска UDP флуда
iperf3 -c 10.45.0.1 -B 10.45.0.3 -u -b 50M -t 60
```

### Терминал 4: Запуск DP-Guard в реальном времени
Перейдите в папку проекта DP-Guard:
```bash
cd ~/Projects/DP_Guard
# Запуск сквозного замкнутого контура на интерфейсе ядра ogstun
python main.py live-5g --interface ogstun --epochs 3 --simulate-attack
```
*(Или с ключом Gemini API: `python main.py live-5g --interface ogstun --epochs 3 --llm`)*.

## 6. ЧТО ПРОИСХОДИТ В РЕАЛЬНОМ ВРЕМЕНИ НА СТЕНДЕ

1. **Эпоха 1:** 
   - DP-Guard считывает телеметрию прямо с интерфейса ядра `ogstun`.
   - Локальный анклав защищает сырые данные и накладывает шум Лапласа.
   - Главный координатор плодит субагентов: `subagent-threat-mitigator`, `subagent-anomaly-forensics`, `subagent-slice-qos`.
   - Субагенты фиксируют всплеск сбоев и аномальный флуд на `10.45.0.3` и голосуют: `vote='block_traffic'`.
   - Детерминированный Admissibility Verifier одобряет блокировку.
   - Исполнитель `ActionExecutor` мгновенно вставляет в ядро Linux правило: `iptables -I FORWARD -i ogstun -s 10.45.0.3 -j DROP`.
2. **Эпоха 2 и 3:**
   - Трафик атакующего мгновенно обнуляется на интерфейсе `ogstun`.
   - Телеметрия фиксирует спад угрозы до нормы.
   - Субагенты констатируют стабилизацию и переключаются в `monitor_only`.

## 7. СПИСОК СКРИНШОТОВ ДЛЯ КУРСОВОЙ / ОТЧЕТА / ПРЕЗЕНТАЦИИ

Для защиты сделайте следующие **6 скриншотов**:

### 📸 Скриншот 1: Панель Open5GS Web UI
- **Что открыть:** Браузер на `http://localhost:3000` в разделе **Subscribers**.
- **Что должно быть видно:** Список зарегистрированных абонентов с IMSI `999700000000001` и eMBB слайсом (SST: 1, SD: 000001).
- **Подпись в отчете:** *«Рисунок 1. Конфигурация абонентов и параметров слайсинга eMBB в ядре 5G SA (Open5GS Web UI)».*

### 📸 Скриншот 2: Терминал UERANSIM (gNodeB и UE)
- **Что открыть:** Консоли Терминала 1 и Терминала 2.
- **Что должно быть видно:** Логи подключения `nr-gnb` к AMF и создание интерфейсов `uesimtun0` и `uesimtun1` с выделенными IP-адресами `10.45.0.2` и `10.45.0.3`.
- **Подпись в отчете:** *«Рисунок 2. Успешная инициализация базовой станции gNodeB и установление PDU-сессий абонентов UE».*

### 📸 Скриншот 3: Сетевой интерфейс ядра Open5GS UPF (`ogstun`)
- **Что выполнить в консоли:**
  ```bash
  ip a show ogstun
  ```
- **Что должно быть видно:** Наличие TUN-интерфейса `ogstun` с IP `10.45.0.1/16` и счетчиками пакетов.
- **Подпись в отчете:** *«Рисунок 3. Состояние сетевого интерфейса пользовательской плоскости (UPF ogstun) на локальном узле».*

### 📸 Скриншот 4: Работа мультиагентного роя DP-Guard в реальном времени
- **Что открыть:** Консоль выполнения команды `python main.py live-5g --interface ogstun --epochs 3`.
- **Что должно быть видно:**
  - `[LOCAL TELEMETRY ENCLAVE] Raw subscriber records strictly isolated in local memory. Zero cloud leakage.`
  - `[MULTI-AGENT SWARM] Spawned 3 specialized autonomous subagents`
  - Голосование субагентов `[SUBAGENTS CONSENSUS]` и вердикт `[VERIFY] ADMISSIBLE`.
- **Подпись в отчете:** *«Рисунок 4. Координация мультиагентного роя LLM и детерминированная верификация допустимости в DP-Guard».*

### 📸 Скриншот 5: Реальное срабатывание замкнутого контура (Блокировка атаки в iptables)
- **Что выполнить в консоли:**
  ```bash
  sudo iptables -L FORWARD -v -n
  ```
- **Что должно быть видно:** Активное правило `DROP` для входящих пакетов с IP-адреса атакующего `10.45.0.3` на интерфейсе `ogstun`.
- **Подпись в отчете:** *«Рисунок 5. Срабатывание исполнительного механизма Closed-Loop Actuation: блокировка вредоносного трафика на уровне ядра Linux».*

### 📸 Скриншот 6: Журнал аудита безопасности (Audit Log)
- **Что выполнить в консоли:**
  ```bash
  tail -n 1 logs/audit.jsonl | jq .
  ```
- **Что должно быть видно:** JSON-структура со списком субагентов (`multi_agent_swarm`), значениями шума Лапласа, доверительными интервалами и остатком бюджета $\varepsilon$.
- **Подпись в отчете:** *«Рисунок 6. Фрагмент неизменяемого журнала аудита с фиксацией параметров дифференциальной приватности и решений субагентов».*
